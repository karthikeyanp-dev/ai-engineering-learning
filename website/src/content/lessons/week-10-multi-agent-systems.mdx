## Introduction

A single agent, no matter how capable, has limits. It can't specialize deeply in every domain, it struggles with tasks that require different perspectives, and it can get stuck in reasoning loops. Multi-agent systems solve these problems by combining specialized agents that collaborate, debate, and delegate.

Think of it like a company: a solo founder can do everything, but a team with specialized roles — researcher, writer, editor, fact-checker — produces better results faster. The same principle applies to AI agents. But orchestration is the hard part: how do agents communicate? Who decides what? What happens when agents disagree?

In this lesson, you'll learn the core patterns for multi-agent collaboration, build systems with CrewAI, and explore how agent debates can improve reasoning quality.

<Callout type="tip" title="When to Use Multi-Agent" client:load>
  Don't use multi-agent for simple tasks. Multi-agent adds complexity, latency, and cost. Use it when: (1) the task has distinct phases requiring different expertise, (2) quality requires review/validation from another agent, (3) the workload is too large for a single context window, or (4) you need diverse perspectives to reduce bias.
</Callout>

## Multi-Agent Patterns

### Supervisor Pattern

A central "supervisor" agent delegates tasks to specialized workers:

1. User sends a request to the supervisor
2. Supervisor analyzes the task and delegates subtasks to appropriate workers
3. Workers execute and return results
4. Supervisor synthesizes results and responds (or delegates more work)

This is the most common pattern because it's simple and predictable.

<CodeBlock language="python" title="supervisor_pattern.py" client:load>
{`from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage, SystemMessage
from langgraph.graph import StateGraph, START, END
from typing import TypedDict, Annotated, Literal
from langgraph.graph.message import add_messages

# Define agent roles
RESEARCHER_SYSTEM = """You are a research specialist. Given a topic, find key facts,
data points, and relevant information. Be thorough and cite sources."""

WRITER_SYSTEM = """You are a skilled writer. Take research notes and craft clear,
engaging content. Maintain the specified tone and style."""

EDITOR_SYSTEM = """You are a strict editor. Review content for accuracy, clarity,
grammar, and style. Suggest specific improvements or approve the content."""

class MultiAgentState(TypedDict):
    messages: Annotated[list, add_messages]
    next_agent: str
    research_notes: str
    draft: str
    feedback: str
    approved: bool

def supervisor(state: MultiAgentState):
    """Routes to the appropriate agent based on current state."""
    model = ChatOpenAI(model="gpt-4o-mini")
    
    if not state.get("research_notes"):
        return {"next_agent": "researcher"}
    elif not state.get("draft"):
        return {"next_agent": "writer"}
    elif not state.get("approved"):
        return {"next_agent": "editor"}
    else:
        return {"next_agent": "done"}

def researcher(state: MultiAgentState):
    model = ChatOpenAI(model="gpt-4o-mini")
    task = state["messages"][-1].content
    response = model.invoke([
        SystemMessage(content=RESEARCHER_SYSTEM),
        HumanMessage(content=f"Research this topic: {task}")
    ])
    return {"research_notes": response.content, "next_agent": "writer"}

def writer(state: MultiAgentState):
    model = ChatOpenAI(model="gpt-4o-mini")
    response = model.invoke([
        SystemMessage(content=WRITER_SYSTEM),
        HumanMessage(content=f"Write an article based on these notes:\\n{state['research_notes']}")
    ])
    return {"draft": response.content, "next_agent": "editor"}

def editor(state: MultiAgentState):
    model = ChatOpenAI(model="gpt-4o-mini")
    response = model.invoke([
        SystemMessage(content=EDITOR_SYSTEM),
        HumanMessage(content=f"Review this draft. Reply APPROVED if good, or provide feedback:\\n{state['draft']}")
    ])
    approved = "APPROVED" in response.content.upper()
    return {"feedback": response.content, "approved": approved, "next_agent": "done" if approved else "writer"}

def route_agent(state: MultiAgentState):
    if state.get("approved"):
        return END
    return state["next_agent"]

# Build the graph
graph = StateGraph(MultiAgentState)
graph.add_node("supervisor", supervisor)
graph.add_node("researcher", researcher)
graph.add_node("writer", writer)
graph.add_node("editor", editor)

graph.add_edge(START, "supervisor")
graph.add_conditional_edges("supervisor", route_agent, {
    "researcher": "researcher", "writer": "writer", "editor": "editor", END: END
})
graph.add_edge("researcher", "supervisor")
graph.add_edge("writer", "supervisor")
graph.add_edge("editor", "supervisor")

app = graph.compile()
`}
</CodeBlock>

### Hierarchical Pattern

Multiple levels of supervision — a top-level supervisor delegates to mid-level managers, who delegate to workers. Useful for very complex tasks with distinct domains.

### Collaborative (Debate) Pattern

Agents discuss and critique each other's work to reach better conclusions:

<CodeBlock language="python" title="agent_debate.py" client:load>
{`from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage, SystemMessage, AIMessage

def agent_debate(question: str, rounds: int = 3) -> str:
    """Two agents debate a question to reach a better answer."""
    model = ChatOpenAI(model="gpt-4o-mini")
    
    advocate_system = """You are an advocate who argues FOR the proposed answer.
    Make your case clearly with evidence. Respond to the critic's objections.
    Be willing to adjust your position based on valid critiques."""
    
    critic_system = """You are a critic who challenges the proposed answer.
    Look for logical flaws, missing considerations, and weak evidence.
    Be constructive — suggest improvements, don't just tear down.
    Acknowledge valid points from the advocate."""
    
    judge_system = """You are an impartial judge. Review the debate and
    synthesize the best answer based on both sides' arguments.
    Explain your reasoning clearly."""
    
    # Initial answer from advocate
    advocate_history = [SystemMessage(content=advocate_system)]
    critic_history = [SystemMessage(content=critic_system)]
    
    advocate_history.append(HumanMessage(content=f"Answer this question: {question}"))
    initial_answer = model.invoke(advocate_history)
    advocate_history.append(initial_answer)
    
    debate_log = f"Advocate: {initial_answer.content}\\n\\n"
    
    for round_num in range(rounds):
        # Critic responds
        critic_history.append(HumanMessage(content=f"The advocate says: {initial_answer.content if round_num == 0 else advocate_response.content}. Critique this."))
        critic_response = model.invoke(critic_history)
        critic_history.append(critic_response)
        debate_log += f"--- Round {round_num + 1} ---\\nCritic: {critic_response.content}\\n\\n"
        
        # Advocate responds to critique
        advocate_history.append(HumanMessage(content=f"The critic says: {critic_response.content}. Respond to their objections."))
        advocate_response = model.invoke(advocate_history)
        advocate_history.append(advocate_response)
        debate_log += f"Advocate: {advocate_response.content}\\n\\n"
    
    # Judge synthesizes
    judge_response = model.invoke([
        SystemMessage(content=judge_system),
        HumanMessage(content=f"Question: {question}\\n\\nDebate transcript:\\n{debate_log}\\n\\nProvide the best answer based on this debate.")
    ])
    
    return judge_response.content

# Run a debate
result = agent_debate("Should companies use RAG or fine-tuning for domain-specific QA?")
print(result)
`}
</CodeBlock>

<Callout type="warning" title="Debate Cost vs. Benefit" client:load>
  Agent debates multiply token usage — each round uses 2-3x the tokens of a single agent. Use debates for high-stakes decisions where accuracy matters more than cost, not for routine tasks. A single agent with good prompting is often sufficient.
</Callout>

## Building with CrewAI

CrewAI is the most popular framework for multi-agent systems. It provides a clean abstraction for defining agents, tasks, and crews:

<CodeBlock language="python" title="crewai_pipeline.py" client:load>
{`from crewai import Agent, Task, Crew, Process
from crewai.llm import LLM

# Define the LLM
llm = LLM(model="gpt-4o-mini")

# Define Agents — each has a role, goal, and backstory
researcher = Agent(
    role="Senior Research Analyst",
    goal="Find comprehensive, accurate information on the given topic",
    backstory="""You are a veteran research analyst at a top consulting firm.
    You excel at finding relevant data, identifying trends, and synthesizing
    information from multiple sources. You always cite your sources.""",
    llm=llm,
    verbose=True,
    allow_delegation=False
)

writer = Agent(
    role="Content Writer",
    goal="Transform research into engaging, well-structured content",
    backstory="""You are an award-winning writer who specializes in turning
    complex topics into clear, engaging articles. You write with authority
    while remaining accessible to a general audience.""",
    llm=llm,
    verbose=True,
    allow_delegation=False
)

editor = Agent(
    role="Fact-Checker and Editor",
    goal="Ensure all content is accurate, well-written, and publication-ready",
    backstory="""You are a meticulous editor with 20 years of experience.
    You catch factual errors, improve clarity, and ensure consistency.
    You never approve content with unsubstantiated claims.""",
    llm=llm,
    verbose=True,
    allow_delegation=False
)

# Define Tasks — each assigned to an agent
research_task = Task(
    description="""Research the topic: {topic}.
    Find: key statistics, expert opinions, recent developments, and potential controversies.
    Provide a structured summary with sources.""",
    expected_output="A structured research report with 5-10 key findings and sources",
    agent=researcher
)

writing_task = Task(
    description="""Using the research findings, write a comprehensive article about: {topic}.
    Include: an engaging introduction, 3-5 main sections with data, and a conclusion with actionable takeaways.
    Target length: 800-1200 words.""",
    expected_output="A polished article in markdown format, 800-1200 words",
    agent=writer
)

editing_task = Task(
    description="""Review the article for:
    1. Factual accuracy — verify all claims against the research
    2. Clarity and readability — suggest improvements
    3. Structure and flow — ensure logical progression
    Approve the article or request specific revisions.""",
    expected_output="A final approved article with any corrections applied",
    agent=editor
)

# Create the Crew — sequential process
content_crew = Crew(
    agents=[researcher, writer, editor],
    tasks=[research_task, writing_task, editing_task],
    process=Process.sequential,  # Tasks execute in order
    verbose=True
)

# Run the crew
result = content_crew.kickoff(inputs={"topic": "The impact of AI agents on software development"})
print(result)
`}
</CodeBlock>

<Callout type="important" title="Single Agent vs. Multi-Agent Decision Framework" client:load>
  Use a **single agent** when:
  - The task is straightforward (1-3 steps)
  - One domain of knowledge is sufficient
  - Speed and cost are priorities
  
  Use **multi-agent** when:
  - The task has distinct phases (research → write → review)
  - You need different perspectives or expertise
  - Quality validation is critical
  - The task exceeds a single agent's effective context window
</Callout>

## Summary

- **Supervisor pattern** is the most common — a central router delegates to specialized workers
- **Debate pattern** improves reasoning quality through adversarial critique, at higher cost
- **CrewAI** provides the simplest abstraction: define agents, tasks, and process type
- Use multi-agent when tasks have **distinct phases** or require **different expertise**
- Always consider whether the added complexity of multi-agent is justified for your use case
