## Introduction

While LangChain is the most popular framework, it's not always the best choice. **LlamaIndex** excels at data ingestion and retrieval, **Haystack** shines for search-focused pipelines, and **Semantic Kernel** integrates deeply with Microsoft's ecosystem. Understanding the strengths and trade-offs of each framework is crucial for making informed architectural decisions.

This week you'll build the same RAG system in multiple frameworks, giving you first-hand experience with their different approaches. You'll develop a decision matrix that you can reference throughout your career.

<Callout type="tip" title="Framework Fatigue" client:load>
  Don't try to learn every framework deeply. Instead, understand their philosophies and sweet spots. Pick one as your primary tool and know when to reach for alternatives.
</Callout>

## LlamaIndex: Data-Centric AI

LlamaIndex is designed around the concept of **indexing your data** for optimal retrieval. Its abstractions focus on data connectors, indices, and query engines.

<CodeBlock language="python" title="llamaindex_rag.py" client:load>
{`from llama_index.core import (
    VectorStoreIndex,
    SimpleDirectoryReader,
    Settings,
    StorageContext,
)
from llama_index.embeddings.openai import OpenAIEmbedding
from llama_index.llms.openai import OpenAI
from llama_index.core.node_parser import SentenceSplitter

# Configure global settings
Settings.llm = OpenAI(model="gpt-4o", temperature=0)
Settings.embed_model = OpenAIEmbedding(model="text-embedding-3-small")

# Load and parse documents
documents = SimpleDirectoryReader("./data").load_data()
node_parser = SentenceSplitter(chunk_size=512, chunk_overlap=50)
nodes = node_parser.get_nodes_from_documents(documents)

# Create index with custom storage
index = VectorStoreIndex(nodes)

# Query with advanced retrieval
query_engine = index.as_query_engine(
    similarity_top_k=5,
    response_mode="tree_summarize",  # Hierarchical summarization
)

response = query_engine.query(
    "What are the key principles of RAG system design?"
)
print(response)
print(f"Sources: {[n.node.metadata for n in response.source_nodes]}")
`}
</CodeBlock>

<Callout type="info" title="LlamaIndex Strength" client:load>
  LlamaIndex's killer feature is its **data connectors hub** — 160+ integrations for loading data from Slack, Notion, databases, APIs, and more. If your application is primarily about structuring and querying diverse data sources, LlamaIndex is likely your best choice.
</Callout>

## Haystack: Search-Focused Pipelines

Haystack uses a pipeline architecture with explicit component connections, making it intuitive for search and retrieval workloads.

<CodeBlock language="python" title="haystack_rag.py" client:load>
{`from haystack import Pipeline
from haystack.components.converters import TextFileToDocument
from haystack.components.preprocessors import DocumentSplitter
from haystack.components.embedders import (
    SentenceTransformersDocumentEmbedder,
    SentenceTransformersTextEmbedder,
)
from haystack.components.writers import DocumentWriter
from haystack.components.retrievers.in_memory import InMemoryEmbeddingRetriever
from haystack.components.generators import OpenAIGenerator
from haystack.components.builders.prompt_builder import PromptBuilder
from haystack.document_stores.in_memory import InMemoryDocumentStore

# Indexing pipeline
document_store = InMemoryDocumentStore()

indexing = Pipeline()
indexing.add_component("converter", TextFileToDocument())
indexing.add_component("splitter", DocumentSplitter(split_by="sentence", split_length=3))
indexing.add_component("embedder", SentenceTransformersDocumentEmbedder())
indexing.add_component("writer", DocumentWriter(document_store=document_store))

indexing.connect("converter", "splitter")
indexing.connect("splitter", "embedder")
indexing.connect("embedder", "writer")

# Query pipeline
template = """Answer based on context:\\n{% for doc in documents %}{{ doc.content }}{% endfor %}\\nQuestion: {{ question }}"""

query_pipeline = Pipeline()
query_pipeline.add_component("embedder", SentenceTransformersTextEmbedder())
query_pipeline.add_component("retriever", InMemoryEmbeddingRetriever(document_store=document_store))
query_pipeline.add_component("prompt", PromptBuilder(template=template))
query_pipeline.add_component("llm", OpenAIGenerator(model="gpt-4o"))

query_pipeline.connect("embedder.embedding", "retriever.query_embedding")
query_pipeline.connect("retriever", "prompt.documents")
query_pipeline.connect("prompt", "llm")

result = query_pipeline.run({"embedder": {"text": "How does RAG work?"}, "prompt": {"question": "How does RAG work?"}})
`}
</CodeBlock>

## Framework Selection Guide

Use this decision tree for selecting frameworks:

<Callout type="important" title="Selection Decision Tree" client:load>
  1. **Need complex agent workflows with cycles?** → LangGraph
  2. **Primary focus is data ingestion and retrieval?** → LlamaIndex
  3. **Building search-first applications?** → Haystack
  4. **Microsoft ecosystem / .NET integration?** → Semantic Kernel
  5. **Multi-agent collaboration?** → CrewAI or AutoGen
  6. **Simple tool-calling agents?** → Phidata or direct API calls
</Callout>
