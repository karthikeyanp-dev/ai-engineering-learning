## LoRA Hyperparameter Guide

| Parameter | Range | Effect | Guidance |
|-----------|-------|--------|----------|
| **rank (r)** | 4-128 | Model capacity | Start at 16, increase if underfitting |
| **alpha** | 8-256 | Learning rate scaling | Usually 2x rank |
| **target_modules** | varies | Which layers adapt | Start with q,v; add k,o,mlp for more capacity |
| **dropout** | 0.0-0.1 | Regularization | Use 0.05 for small datasets |
| **learning_rate** | 1e-5 to 2e-4 | Training speed | 2e-4 for QLoRA is common |
| **epochs** | 1-5 | Training duration | 2-3 epochs typical; watch for overfitting |
| **batch_size** | 1-8 | Gradient stability | Larger = more stable, more VRAM |

    load_in_4bit=True,
    bnb_4bit_quant_type="nf4",
    bnb_4bit_compute_dtype=torch.bfloat16,
    bnb_4bit_use_double_quant=True,
)

# Load model

    model_name, quantization_config=bnb_config, device_map="auto"
)
tokenizer = AutoTokenizer.from_pretrained(model_name)
tokenizer.pad_token = tokenizer.eos_token
tokenizer.padding_side = "right"

model = prepare_model_for_kbit_training(model)

# LoRA config - experiment with these values
lora_config = LoraConfig(
    r=16,
    lora_alpha=32,
    target_modules=["q_proj", "k_proj", "v_proj", "o_proj", "gate_proj", "up_proj", "down_proj"],
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM",
)
model = get_peft_model(model, lora_config)

# Load your prepared dataset
dataset = load_dataset("json", data_files="training_data.jsonl", split="train")
dataset = dataset.train_test_split(test_size=0.1)

# Training arguments
training_args = TrainingArguments(
    output_dir="./results/llama3-customer-support",
    num_train_epochs=3,
    per_device_train_batch_size=4,
    gradient_accumulation_steps=4,  # Effective batch size = 16
    warmup_ratio=0.1,
    learning_rate=2e-4,
    fp16=False,
    bf16=True,
    logging_steps=10,
    eval_strategy="steps",
    eval_steps=50,
    save_strategy="steps",
    save_steps=100,
    save_total_limit=3,
    load_best_model_at_end=True,
    metric_for_best_model="eval_loss",
    report_to="wandb",
    gradient_checkpointing=True,
    optim="paged_adamw_8bit",
)

# Initialize trainer
trainer = SFTTrainer(
    model=model,
    args=training_args,
    train_dataset=dataset["train"],
    eval_dataset=dataset["test"],
    tokenizer=tokenizer,
    max_seq_length=2048,
    dataset_text_field="text",
    packing=True,  # Pack multiple examples into one sequence
)

# Train!
trainer.train()

# Save the adapter
trainer.save_model("./final_model")
wandb.finish()
`}

<Callout type="tip" title="Reading Training Curves" client:load>
  **Healthy training**: Train loss decreases smoothly, eval loss decreases then plateaus.
  **Overfitting**: Train loss keeps decreasing but eval loss starts increasing — stop training or increase dropout.
  **Underfitting**: Both losses plateau high — increase rank, add target modules, or train longer.
</Callout>

## Detecting and Preventing Overfitting

| Signal | Diagnosis | Fix |
|--------|-----------|-----|
| Eval loss increasing | Overfitting | Early stopping, more data, increase dropout |
| Train loss oscillating | Learning rate too high | Reduce LR, increase warmup |
| Both losses high | Underfitting | Increase rank/modules, more epochs |
| Repetitive outputs | Memorization | More diverse data, lower temperature |
| Catastrophic forgetting | Too much training | Fewer epochs, lower LR, regularization |

<CodeBlock language="python" title="overfitting_detection.py" client:load>
{`from transformers import TrainerCallback

class OverfittingDetector(TrainerCallback):
    """Early stopping with overfitting detection."""
    
    def __init__(self, patience=5, min_delta=0.01):
        self.patience = patience
        self.min_delta = min_delta
        self.best_eval_loss = float("inf")
        self.wait = 0
    
    def on_evaluate(self, args, state, control, metrics, **kwargs):
        eval_loss = metrics.get("eval_loss", float("inf"))
        
        if eval_loss < self.best_eval_loss - self.min_delta:
            self.best_eval_loss = eval_loss
            self.wait = 0
        else:
            self.wait += 1
            if self.wait >= self.patience:
                print(f"Early stopping! No improvement for {self.patience} evaluations.")
                control.should_training_stop = True

# Add to trainer
trainer = SFTTrainer(
    ...,
    callbacks=[OverfittingDetector(patience=5)],
)
`}
</CodeBlock>

<Callout type="warning" title="Common Pitfall" client:load>
  Don't train for too many epochs on small datasets. With 500 examples, 2-3 epochs is usually sufficient. Beyond that, the model memorizes training examples rather than learning generalizable patterns. Monitor eval loss closely.
</Callout>

## Summary

1. Fine-tuning is an experimental process — plan for 3-5 experiments minimum
2. Start with rank 16, alpha 32, targeting q/v projections, then scale up if needed
3. Monitor both train and eval loss; divergence indicates overfitting
4. Use gradient checkpointing and packing to maximize training efficiency
5. Track everything in W&B — you'll thank yourself when comparing results later
