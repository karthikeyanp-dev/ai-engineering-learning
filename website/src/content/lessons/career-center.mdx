## Interview Preparation

### Interview Format Overview

Most AI engineering interviews include 4-6 rounds:

1. **Recruiter Screen** (30 min) — Background, motivation, salary expectations
2. **Technical Phone Screen** (60 min) — Coding + AI concepts
3. **System Design** (60 min) — Design an AI system end-to-end
4. **LLM Deep Dive** (60 min) — RAG, agents, evaluation, fine-tuning
5. **Coding** (60 min) — Python, data structures, algorithms
6. **Behavioral** (45 min) — Past projects, collaboration, ambiguity

from typing import Any

async def parallel_llm_calls(prompts: list[str], max_concurrent: int = 5) -> list[str]:
    """Process multiple LLM calls with concurrency control."""
    semaphore = asyncio.Semaphore(max_concurrent)
    
    async def bounded_call(prompt: str) -> str:
        async with semaphore:
            # Simulate LLM API call
            await asyncio.sleep(0.5)
            return f"Response to: {prompt}"
    
    tasks = [bounded_call(p) for p in prompts]
    return await asyncio.gather(*tasks)

# Pattern 2: Sliding window for context management
def sliding_window_context(messages: list[dict], max_tokens: int = 4000) -> list[dict]:
    """Keep conversation history within token budget."""
    # Always keep system message
    system = [m for m in messages if m["role"] == "system"]
    history = [m for m in messages if m["role"] != "system"]
    
    selected = []
    token_count = sum(len(m["content"].split()) for m in system) * 1.3
    
    # Add messages from most recent, working backwards
    for msg in reversed(history):
        msg_tokens = len(msg["content"].split()) * 1.3
        if token_count + msg_tokens > max_tokens:
            break
        selected.insert(0, msg)
        token_count += msg_tokens
    
    return system + selected

# Pattern 3: Retry with exponential backoff (production essential)
import random

async def retry_with_backoff(func, max_retries: int = 3, base_delay: float = 1.0):
    """Retry failed API calls with jitter."""
    for attempt in range(max_retries):
        try:
            return await func()
        except Exception as e:
            if attempt == max_retries - 1:
                raise
            delay = base_delay * (2 ** attempt) + random.uniform(0, 1)
            await asyncio.sleep(delay)

### LLM-Specific Interview Questions

**Expect questions on:**

1. **Tokenization** — "How does BPE work? Why do some words get split into multiple tokens?"
2. **Attention** — "Explain self-attention. What's the computational complexity? How does KV-cache help?"
3. **RAG** — "Design a RAG pipeline for [X]. How do you handle [edge case]? How do you evaluate it?"
4. **Agents** — "What's the difference between ReAct and Plan-and-Execute? When would you use each?"
5. **Fine-tuning** — "When would you fine-tune vs. use RAG? Explain LoRA. What data do you need?"
6. **Evaluation** — "How do you measure if your RAG system is working? What metrics? How do you build eval sets?"

### System Design for AI — Common Questions

| Question | Key Topics to Cover |
|----------|-------------------|
| Design a RAG-powered customer support chatbot | Multi-tenant, routing, escalation, caching |
| Design a document processing pipeline | Ingestion, chunking, OCR, metadata, scale |
| Design a content moderation system | Real-time, multi-modal, appeals, accuracy |
| Design an AI code assistant | Context gathering, latency, privacy, learning |
| Design a recommendation system with LLMs | Personalization, cold start, A/B testing |

### Behavioral Interview Tips

**Key themes for AI roles:**
- **Handling ambiguity** — "Tell me about a time you had unclear requirements for an AI feature"
- **Technical judgment** — "When did you choose a simpler approach over a more sophisticated one?"
- **Communication** — "How do you explain AI limitations to non-technical stakeholders?"
- **Iteration** — "Describe a time your first approach didn't work and how you adapted"

<Callout type="warning" title="Common Interview Mistakes" client:load>
  1. Over-engineering solutions (use GPT-4o-mini when it works, don't jump to fine-tuning)
  2. Ignoring cost/latency in system design (always discuss trade-offs)
  3. Not asking clarifying questions (requirements matter!)
  4. Focusing only on the AI parts (ignore infra/scale at your peril)
  5. No evaluation strategy (if you can't measure it, interviewers worry)
</Callout>
