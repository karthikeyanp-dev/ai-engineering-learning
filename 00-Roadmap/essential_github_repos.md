3. **ollama/ollama** — Essential for local development and testing
4. **mlabonne/llm-course** — Best structured learning path
5. **vllm-project/vllm** — Production inference standard

7. **langchain-ai/langgraph** — Agent orchestration standard
8. **karpathy/nn-zero-to-hero** — Deep understanding of fundamentals
9. **rasbt/LLMs-from-scratch** — Build intuition by building from zero

## Suggested Learning Path

1. **Foundations** → nn-zero-to-hero, d2l-en, LLMs-from-scratch
2. **Prompt Engineering** → Prompt-Engineering-Guide, openai-cookbook, dspy
3. **Frameworks** → langchain, llama_index, transformers
4. **RAG** → RAG_Techniques, chroma/qdrant, ragas
5. **Agents** → langgraph, crewAI, autogen
6. **Fine-Tuning** → unsloth, axolotl, trl, peft
7. **Production** → vllm, ollama, litellm, langfuse, BentoML
